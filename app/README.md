# StopIncrust app (Flutter — iOS + Android)

Single Dart codebase in `lib/`. Platform folders (`android/`, `ios/`) are generated by `flutter create`.

## Prerequisites (Windows)

1. Install the Flutter SDK: download the stable zip from https://docs.flutter.dev/get-started/install/windows, extract to `C:\flutter`, and add `C:\flutter\bin` to your PATH (System Properties → Environment Variables → Path → New).
2. Install **Android Studio** (for the emulator + SDK). Accept licenses: `flutter doctor --android-licenses`.
3. In VS Code, install the extensions **Dart** and **Flutter**.

## First run

```powershell
cd app
flutter create .        # generates android/ and ios/ platform folders (lib/ is already here)
flutter pub get
# put your local Supabase keys in lib/config.dart (from `supabase status`: Project URL + Publishable key)
```

Then in VS Code: bottom-right corner → pick a device (create an Android emulator in Android Studio: Device Manager → Create Device), then press **F5** (Run).

## Notes

- `lib/config.dart`: for the Android emulator use `http://10.0.2.2:54321`; for a real phone use your PC's LAN IP (both must be on the same Wi-Fi).
- If the app cannot reach the backend over plain HTTP on Android, add `android:usesCleartextTraffic="true"` to `app/android/app/src/main/AndroidManifest.xml` (in the `<application>` tag).
- Local login: phone OTP is auto-confirmed (see `supabase/config.toml` → `[auth.sms] autoconfirm`), so you land in the app right after "Send OTP".
- The **Secret** (`sb_secret_...`) key must never be in the app — only the **Publishable** key.
